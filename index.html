Profil

Perkenalkan Saya Richardo Reksi Ratag, lahir pada 10 April 2006 di Tanah Grogot. Saat ini saya sedang menempuh pendidikan sebagai Mahasiswa Pendidikan Komputer di FKIP Universitas Mulawarman.

Minat

Saya tertarik pada dunia teknologi, pengembangan web, serta pembuatan media dan sistem yang dapat membantu proses belajar maupun kebutuhan digital sehari-hari. Saya juga tertarik di bidang cyber security di karenakan saya dulu pernah mengikuti Lomba Cyber Security sebagai siswa SMKN 1 Tanah Grogot.

Tujuan

Saya ingin terus mengembangkan kemampuan di bidang pemrograman, seperti menguasai backend dalam pembrograman, tetapi jika mungkin saya sanggup, saya ingin coba menjadi fullstack developer walaupun terdengar mustahil, saya juga masih antusias dengan bidang bidang Cyber Security dan ingin menguasai semua jenis jenis keamanan seperti di Networking.
